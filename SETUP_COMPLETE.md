## 🐛 Troubleshooting

### Buttons Don't Work?
1. Open browser console (F12 → Console)
2. Look for red error messages
3. Run `test-setup.html` to diagnose
4. Check if all files are in the same folder

### PDF is Empty?
1. Make sure you filled out some fields
2. Try clicking "Preview" first
3. Check browser console for errors
4. Try a different browser (Chrome recommended)

### Markdown Not Copying?
1. Browser might block clipboard access
2. Try the fallback method (will show alert)
3. Or use "Download Markdown" instead

### Styles Not Loading?
1. Make sure `styles.css` is in the same folder
2. Check browser Network tab (F12 → Network)
3. Try hard refresh (Ctrl+Shift+R)
