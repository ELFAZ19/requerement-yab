# 🚀 Quick Start Guide

## ⚡ 3-Step Test

### Step 1: Test PDF Library
```
1. Open: test-pdf.html
2. Click: "1. Check if Library Loaded"
3. Should see: ✅ SUCCESS
4. Click: "2. Generate Test PDF"
5. PDF downloads automatically
```

### Step 2: Test Main App
```
1. Open: index.html
2. Press: Ctrl + Shift + R (hard refresh)
3. Click theme toggle ☀️ (should work)
4. Click navigation tabs (should work)
```

### Step 3: Generate Real PDF
```
1. Fill in:
   - Client name: "Test Client"
   - Project name: "Test Project"
   - Select 2-3 features
2. Click: "Export Proposal" (top right)
3. Click: "Print / Save as PDF"
4. Wait 2-5 seconds
5. PDF downloads to Downloads folder
```

---

## ✅ If Everything Works

**You're done! Start using the app.**

## ❌ If Something Doesn't Work

### Buttons not working?
```
1. Press: Ctrl + Shift + R
2. Press: F12 (check console for errors)
3. Verify files exist:
   - app.js
   - styles.css
   - pdf-generator.js
```

### PDF not downloading?
```
1. Check internet connection (needs CDN)
2. Open: test-pdf.html
3. Test library loading
4. Try different browser (Chrome/Edge)
```

### PDF is empty?
```
1. Fill in some data first
2. Wait for "Generating PDF..." to finish
3. Don't close page during generation
```
